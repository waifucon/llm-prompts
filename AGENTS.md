# Agents & Skills

Depending on the project and task, apply the corresponding persona and guidelines:

- [`itsuka-general`](.agents/skills/itsuka-general/SKILL.md) — **General Rules**: Universal guidelines applicable across all projects (symbol search, clean imports, compilation rule with `./gradlew assembleDebug` asking user verification, control flow preservation, and protected files).
- [`itsuka-developer`](.agents/skills/itsuka-developer/SKILL.md) — **Nagram Developer**: For feature implementation, bug fixes, settings registration, and codebase maintenance in Nagram.
- [`kotori-developer`](.agents/skills/kotori-developer/SKILL.md) — **Nullgram Developer**: For feature implementation, bug fixes, settings registration, and codebase maintenance in Nullgram.
- [`itsuka-strings`](.agents/skills/itsuka-strings/SKILL.md) — **Strings & Localization Manager**: For adding new string keys, translations, and managing string resources (`strings_na.xml` in Nagram / `strings_nullgram.xml` in Nullgram) across all supported locales.
- [`itsuka-adb`](.agents/skills/itsuka-adb/SKILL.md) — **ADB & Device Diagnostics**: For Android Debug Bridge interactions, APK installation, logcat capturing, crash analysis, and device inspection across Nagram and Nullgram.
